All notable changes to this project are documented in this file.

## [0.1.0] - 2026-09-19

### Added

- Persistent JSONL client for `codex app-server`.
- LangChain chat model with synchronous and asynchronous invocation.
- Text, image, tool-call, and structured-output support.
- Bounded image resizing and compression.
- Cross-platform Codex binary discovery and login status checks.
- Offline unit tests, CI matrix, live smoke test, and trusted publishing workflow.
